# Bedrock Capability Matrix

Status as of 2026-11-26 on main at `cbaed03`. “Automated” means deterministic local XCTest coverage. “Device” requires an exported artifact imported into the exact Minecraft release on a physical iPhone with a clean Content Log. The milestone sweep ran all fourteen `minecraft-e2e` scenarios green on the iPhone 13 Pro; every Content Log error it surfaced was fixed and re-verified with a focused run. Device claims below state exactly what each scenario exercised — crafting an item does not prove placing, eating, smelting, brewing, upgrading, growing, equipping, or combat with it.

Project roadmap, milestone status, and decisions are maintained in Orca at `~/workspace/repo-notes/projects/craftberry/`. This file remains the repository-facing capability and verification reference.

## Status meanings

- **Implemented** means the support is present on main; it does not imply gameplay acceptance.
- **Partial** means some content or narrower behavior exists, but the roadmap acceptance above is incomplete.
- **In progress** means work exists only on a local/unmerged branch and is not yet shipped.
- **Pending** means no current main implementation or acceptance evidence supports the roadmap claim.
